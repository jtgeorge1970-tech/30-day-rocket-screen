## Five-day validation protocol
1. Never manufacture a fixed five-stock list.
2. Each validation day records each engine's actual surviving funnel and candidate names under that engine's locked rules.
3. Engine 1 records its current finalist/Crown status and any material thesis or technical change.
4. Engine 2 records pool, bottom-confirmed, entry-geometry, research and ENTRY_READY counts/names.
5. Engine 3 records automated pass, Top 5, Top 3, current-verification and ENTRY_READY counts/names.
6. Only actual survivors are carried forward. Zero is a valid result.
7. Standardized visual verification is applied only to the actual final Top 3-5 / WATCH candidates and never overrides failed mandatory gates.
8. Preserve each daily result so persistence can be compared across the complete validation window.
